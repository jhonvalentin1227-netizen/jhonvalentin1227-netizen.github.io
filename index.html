Local GitHub Folder Architecture

How to organize your files inside jhonvalentin1227-netizen.github.io for full control over Akamai caching.

Repository Tree: 
jhonvalentin1227-netizen.github.io/
├── index.html                 (This dashboard)
├── images/                    (Local image folder)
│   ├── dimtec.jpeg            (Your image)
│   ├── logo.png
│   └── banner.jpg
└── fonts/                     (Local fonts folder)
    ├── CustomFont.woff2
    └── CustomMono.woff2
1. Adding Images

Upload your images into images/. Reference them in HTML using relative paths like src="images/tu-imagen.jpg".

2. Adding Custom Fonts

Place .woff2 font files inside fonts/. The CSS in this page automatically links to them.

3. Akamai Edge Rule

Ensure Akamai Property Manager matches paths like /images/* to enforce your preferred Cache TTL (e.g. 30 days).
