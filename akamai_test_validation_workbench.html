Step-by-Step Guide: Hosting on GitHub Pages & Linking to Akamai

Complete roadmap to deploy this test suite as a free, highly-available origin for Akamai Staging tests.

1

Upload this Page to GitHub

Create a public repository named akamai-test-suite. Save this HTML file as index.html in the root directory and push it to GitHub.

git init
git add index.html
git commit -m "Initial Akamai test suite"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/akamai-test-suite.git
git push -u origin main
2

Enable GitHub Pages

Go to your repository **Settings > Pages**. Under **Build and deployment > Branch**, select main and click **Save**.

Your origin URL will be: https://YOUR-USERNAME.github.io/akamai-test-suite/

3

Configure Origin Server in Akamai Property Manager

Open **Akamai Control Center**, go to **Property Manager**, and configure your origin behavior:

Origin Server Hostname: YOUR-USERNAME.github.io
Forward Host Header: Origin Hostname
4

Force Traffic to Akamai Staging Network

Find your Staging Edge Hostname (e.g. test.tudominio.com.edgekey-staging.net) and resolve its IP via terminal:

nslookup test.tudominio.com.edgekey-staging.net

Add the output IP to your local hosts file (C:\Windows\System32\drivers\etc\hosts on Windows or /etc/hosts on Mac/Linux):

23.211.243.19 test.tudominio.com
